# NanoSeal — версия для GitHub Pages

Статический демонстрационный сайт: **не требует Python, сервера, npm или сборки**.

## Публикация

1. Создайте публичный репозиторий `nanoseal` на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория (`index.html`, `admin.html`, `assets/`, `.nojekyll`).
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите `main` и `/(root)`, нажмите **Save**.
5. После публикации откройте `https://ВАШ-ЛОГИН.github.io/nanoseal/`.

## Что работает

- Две адаптивные страницы и анимации.
- Выпуск цифровых паспортов и ECDSA P-256 подпись через Web Crypto API.
- QR в SVG, скачивание и печать.
- Проверка настоящей и изменённой подписи, демонстрация отзыва.
- Локальный реестр на устройстве в `localStorage`.

## Ограничения (важно)

**Это учебный MVP, не сервис реальной защиты от контрафакта.** GitHub Pages не предоставляет серверную базу, аутентификацию или защищённое хранилище закрытого ключа. Закрытый ключ генерируется в браузере и хранится в `localStorage` текущего устройства. Публичный ключ входит в токен: математически подпись проверяется, **но нельзя доказать, что её сделал конкретный производитель**. Любой посетитель может создать собственный подписанный код. Статус отзыва существует только в том браузере, где создан код, и не синхронизируется между устройствами. Для настоящей проверки статуса и происхождения нужен серверный API, общая база и защищённые ключи.

Данные исчезнут при очистке хранилища браузера. Не вводите реальные производственные данные. Для проверки QR с телефона разместите сайт на GitHub Pages; URL в QR будет вести на опубликованную страницу.

Сторонний QR-генератор основан на QRCode for JavaScript (Kazuhiko Arase, MIT); лицензия в `assets/QRCode_LICENSE.txt`.
